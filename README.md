# Народный реактив — лендинг

Адаптивный одностраничный лендинг сервиса **«Народный реактив»** (проект **MMDV**,
младший брат «Народного AI»). Сервис находит в базе стоматологической клиники
«спящих» пациентов и по-человечески возвращает их обратно.

Тёплый, издательский, «народный» характер: тёмный фон, золото, оксблад, огонь,
печати и ненавязчивый медведь-маскот семьи MMDV.

## Что внутри

```
index.html            — разметка всех 7 экранов + шапка/подвал, инлайновые SVG
assets/css/styles.css — бренд-система (палитра, типографика, компоненты), mobile-first
assets/js/app.js      — рабочий калькулятор «спящей» базы + оживления интерфейса
```

Внешних сборок нет — это чистые HTML/CSS/JS. Достаточно открыть `index.html`
в браузере (шрифты Alegreya / Alegreya Sans подтягиваются с Google Fonts).

## Бренд-система

- **Палитра** (CSS-переменные в `:root`): `--ink #160B07`, `--oxblood #7E1A16`,
  `--ember #C13B22`/`--ember-bright #D9542B`, `--gold #C9A24B`/`--gold-bright #EAC976`/`--gold-deep #9A7733`,
  `--cream #F4E7CB`/`--cream-dim #D8C7A0`, `--parchment #F6EDD7`, `--line-gold rgba(201,162,75,.32)`.
- **Типографика**: `Alegreya` (serif, до 900) для заголовков и крупных цифр,
  `Alegreya Sans` для текста и кнопок. Кириллица.
- **Мотивы**: eyebrow-кикер над каждым заголовком, кнопки ember (заливка) и
  ghost (обводка золотом), золотые волосяные линии-разделители, круглая печать-штамп
  и медведь-знак — все иллюстрации оригинальные, инлайновые SVG.

## Калькулятор

Живой пересчёт (слайдер + числовой ввод синхронизированы), русское форматирование чисел:

```
Спящие  = карточки × доля / 100
Вернётся = Спящие × 0,05        (по практике возвращается 4–7 %)
Выручка  = Вернётся × средний чек
```

По умолчанию `2000 × 60 % → 1200 спящих → 60 вернётся × 4000 ₽ = 240 000 ₽`.
